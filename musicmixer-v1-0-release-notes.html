🎵 What's New — Full Feature List

📁 Named Projects
Create, rename, and delete mix projects. Each project saves its own track list, trim states, and settings independently. Switch freely between projects.
🎚️ Multi-track Mixer
Import multiple audio files at once. Drag-to-reorder tracks. Each clip plays sequentially to form a complete mix.
✂️ Inline Waveform Trim
Each track shows an interactive waveform. Slim green ◀ / pink ▶ handles let you set exact start and end points without leaving the main screen.
▶ Per-clip & Global Play
Play any single clip in isolation. Global ▶ button plays all trimmed clips in sequence. Running timer shows exact absolute position (e.g. 1:05 / 2:10).
🎯 Playhead Scrubber
White vertical playhead scrolls during playback. Drag it anywhere within the trimmed region to seek instantly — fires on finger-up only, no snap-back.
🎛️ Mix & Export
Render all trimmed clips into a single WAV file. Preview the mix, share via WhatsApp, share via any app, or save directly to Downloads.
⬇️ URL Download
Paste any YouTube or audio URL. Downloads via NewPipe extractor with cobalt.tools fallback. Download history saved locally.
💾 Auto-save Persistence
All project data (tracks, trim, order) survives app close and reopen. URI permissions re-granted automatically on restore.

⚙️ Technical Highlights

  • Audio engine: MediaCodec + MediaExtractor for low-latency PCM decode; AudioTrack for direct output
  • Fast waveform: Seek-based peak sampling (120 points) — ~0.3 s per track vs ~8 s full decode
  • WAV export: Offline sequential PCM decode → 16-bit stereo WAV render with optional fade-in/out
  • Architecture: MVVM — AndroidViewModel + LiveData + ListAdapter with DiffUtil
  • UI: Material Components dark theme, ViewBinding, no Jetpack Compose
  • Persistence: SharedPreferences JSON per-project store (ProjectStore)
  • URL download: NewPipe Extractor v0.24.2 + OkHttp + cobalt.tools API fallback

🔧 How to Install (Sideload)

  • On your Android device go to Settings → Security (or Apps → Special app access → Install unknown apps) and enable Install from unknown sources for your file manager or browser.
  • Transfer MusicMixer-v1.0-release.apk to your device via USB, WhatsApp, Google Drive, or email.
  • Open the APK file on your device using your file manager and tap Install.
  • Launch MusicMixer from the app drawer. Create a new project and start mixing!

⚠️ Known Limitations

NOTE APK is unsigned — for Play Store distribution it must be signed with a keystore.
NOTE YouTube URL download depends on NewPipe extractor; may break if YouTube changes their API.
NOTE Export produces uncompressed WAV; large mixes (10+ min) can generate files >100 MB.
NOTE Tracks imported from cloud storage (Drive, OneDrive) may not persist across reboots if URI permissions are not grantable.
